# vfbLib-rust

`vfbLib` consists of the packages `vfb-macros` and `vfbreader` that can read VFB
files, the file format of FontLab Studio up until version 5. It includes a
command line utility, `vfbreader`, that will read the entries from a VFB file
and serialize them to JSON.
